# Положите сюда фотографии работ мастера.

Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`

Порядок показа:
- файл `01.*` всегда **первый**
- остальные фото бот раскладывает в случайном (но стабильном) порядке

Рекомендации:
- Размер: до ~4–5 МБ на фото (лучше меньше)
- Соотношение сторон: 3:4 или 1:1 — лучше смотрится в Telegram

Обложка приветствия: `images/welcome/cover.jpg`
(если кладёшь сырое фото — `scripts/prepare_images.py` сожмёт его под Telegram).
