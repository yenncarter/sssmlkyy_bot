# Положите сюда фотографии работ мастера.

Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`

Рекомендации:
- Имена файлов: `01.jpg`, `02.jpg` … (сортировка по алфавиту)
- Размер: до 5 МБ на фото
- Соотношение сторон: 3:4 или 1:1 — лучше смотрится в Telegram

Бот показывает по 10 фото на страницу с кнопками «Назад / Вперёд».

После добавления фото перезапускать бота не нужно — они подхватятся автоматически.
